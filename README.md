# SWYNEX Interactive Dashboard

## Project Overview

This project is part of my SWYNEX Data Analyst Internship.

I created an interactive sales dashboard using Google Data Studio (Looker Studio) to analyze the cleaned transaction dataset.

## Dashboard Features

* Total Spent
* Total Transactions
* Total Quantity Sold
* Average Transaction Value
* Sales by Item
* Sales by Payment Method
* Sales by Location
* Sales Over Time
* Payment Method filter
* Location filter
* Date Range filter

## Tools Used

* Google Sheets
* Google Data Studio (Looker Studio)
* GitHub

## Key Findings

* Total Transactions: 10,000
* Total Quantity Sold: 28,834
* Total Spent: approximately 84,763.5
* The dashboard allows users to interactively filter the data by payment method, location, and date.

## Learning Outcome

Through this task, I learned how to build an interactive dashboard, create KPI cards and charts, add filters, and present data insights visually.
